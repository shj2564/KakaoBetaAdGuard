# 테스트 기록 및 미검증 항목

## 검증 완료

- KakaoTalk Beta: **26.9.2.447**, Qt **6.10.3**
- 광고 로더, 구분선 비표시 및 채팅 목록 **101px 확장**
- 전체 콘텐츠 높이 **677px 유지**
- Qt 채팅 목록 실측 **462→563px**, 별도 창 상태 **446→547px**
- GUI 스레드 DLL + C++ 자동 적용 시험
- 정상 종료 시 광고 요소 복원
- 416×670 → 458×706 창 크기 변경: 채팅 목록 547→583px로 함께 변경
- 다시 416×670 복원 시 확장된 목록으로 유지
- 화면 경계 및 작업표시줄 바로 위 자석 정렬 (테스트 모니터)
- 실제 스크린 캡처로 하단 흰 칸 없음 확인
- Windows `HKCU Run` 자동 실행 등록 존재 확인
- 개발자 PC에서 KakaoTalkUI 및 가드 프로세스 정상 응답
- 사용자 실제 사용 시 성공 판정

## 아직 개별 확인되지 않은 항목

- Windows 시스템 **실제 재부팅 후** 자동 시작
- 모든 모니터와 DPI 스케일 조합
- 모든 친구 탭 레이아웃 상태를 별도 실측한 결과
- 향후 KakaoTalk 버전의 호환성
- 강제 종료나 충돌 등 비정상 종료 후 복원

## 테스트 원칙

새 버전은 **원본 창 높이 그대로 + 실제 목록 높이 증가**를 실측해야 성공입니다. 빈 칸 덮기, 단순 클리핑, 창 크기만 변경하는 방법은 성공 기준이 아닙니다.
