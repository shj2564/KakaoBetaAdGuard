# 개발·수정 이력 (2026-10-28)

## v1.3.0.0 — Qt6 FullHeight (최종 성공본)

- Qt6 내부 객체 1,089개 열람을 통해 실제 레이아웃 구조 식별
- 광고 로더 100px + 구분선 1px를 Qt6 GUI 스레드 안에서 비활성화
- `StackView`와 `ChatRoomList` 실제 높이 +101px 확장
- 원래 창 높이 유지, 외곽선·투명 꼬리 없이 동작
- 마우스 드래그, 창 크기 변경, 작업표시줄 경계 자석 정렬 유지
- 정상 종료 시 레이아웃 원복
- PC 사용자 실사용 성공 확인
- 성공본 SHA-256을 README에 고정

- `QQuickLoader`와 구분선 비활성화 후 레이아웃 자동 갱신 검증
- QML 원본 외부 교체 시험은 실패하여 원본 복원
